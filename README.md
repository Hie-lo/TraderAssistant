# دستیار معاملاتی و مینی‌اپ مدیریت ریسک تلگرام (Trading Assistant & Risk Mini-App)

این پروژه پیاده‌سازی کامل مشخصات فنی اسناد «مرجع مهندسی بک‌اند» و «معماری و نقشه راه» است. سیستم شامل یک مینی‌اپلیکیشن تعاملی تلگرام مبتنی بر React + Tailwind و یک بک‌اند مقیاس‌پذیر و ماژولار مبتنی بر FastAPI، Aiogram 3.x، SQLAlchemy 2.0، APScheduler و ccxt می‌باشد.

---

## ۱. ساختار پروژه

```text
TradeAssistant/
├── docker-compose.yml          # راه‌اندازی همزمان دیتابیس PostgreSQL، بک‌اند و فرانت‌اند
├── .env.example                # نمونه متغیرهای محیطی
├── .env                        # تنظیمات محیط توسعه و سرور
├── backend/
│   ├── requirements.txt        # کتابخانه‌های پایتون
│   ├── alembic.ini             # پیکربندی مهاجرت‌های دیتابیس
│   ├── alembic/                # فایل‌های Migration (نسخه 001_initial_schema)
│   ├── storage/
│   │   ├── charts_auto/        # اسنپ‌شات‌های رندرشده کندل‌استیک با mplfinance
│   │   └── charts_custom/      # تصاویر آپلود شده کاربران (پاک‌سازی و بهینه‌شده به WebP)
│   ├── logs/                   # لاگ‌های ساختاریافته Loguru (app.log و error.log)
│   ├── tests/                  # تست‌های واحد و یکپارچگی (Pytest)
│   └── app/
│       ├── main.py             # Lifespan، راه‌اندازی FastAPI + Aiogram + APScheduler
│       ├── core/               # هسته مرکزی، تنظیمات پویا، HMAC تلگرام، سپر ضد اسپم
│       ├── database/           # سشن Async و مقداردهی اولیه (Seed)
│       ├── models/             # مدل‌های دیتابیس (User, Trade, UserStrategy, Alert, ...)
│       ├── schemas/            # قراردادهای ورودی/خروجی Pydantic با فرمت camelCase
│       ├── repositories/       # لایه دسترسی به داده (Repository Pattern)
│       ├── services/           # منطق محاسباتی، رسم چارت، هشدار دراوداون و صرافی
│       ├── api/                # اندپوینت‌های REST مینی‌اپ (v1)
│       └── bot/                # ربات تعاملی Aiogram 3 (منو، ماشین حالت FSM، غربالگر و ادمین)
└── frontend/                   # مینی‌اپلیکیشن تلگرام (React 18 + Vite + Tailwind CSS)
    ├── src/
    │   ├── App.jsx             # کامپوننت ماشین‌حساب، ژورنال و جزئیات ترید
    │   └── api/client.js       # کلاینت ارتباطی با بک‌اند به همراه احراز هویت تلگرام
```

## ۲. ویژگی‌های کلیدی پیاده‌سازی‌شده

1. **معماری لایه‌ای و جریان وابستگی یک‌طرفه:**
   - رعایت قانون `Delivery -> Service -> Repository -> Model -> Database -> Core` بدون خطای Circular Import.
2. **سیستم تنظیمات دو لایه و کش RAM:**
   - تنظیمات زیرساختی ثابت در `.env` و `core/config.py`.
   - تنظیمات پویای زمان اجرا (`DynamicConfigManager`) با دسترسی $O(1)$ در رم و ماندگاری در جدول `system_settings`.
3. **محاسبات دقیق مالی بدون خطای ممیز شناور:**
   - استفاده از `Decimal` برای تمام محاسبات ورودی، مارجین، حجم، سود و R/R در دو حالت: با حد ضرر و بدون حد ضرر (بر اساس مارجین).
4. **امنیت چندلایه و سپر خودکار:**
   - اعتبارسنجی رمزنگاری امضای HMAC-SHA256 هدر `X-Telegram-Init-Data` همراه با محافظت Anti-Replay.
   - حالت توسعه (`DEV_MODE=development`) برای تست روان در مرورگر بدون نیاز به باز شدن از داخل تلگرام.
   - کش کاربران مسدود در رم (`AccessControlManager`) برای جلوگیری از فشار به دیتابیس.
   - سپر ضد اسپم (Auto-Shield) با اسلایدینگ ویندو: مسدودی خودکار ۱۵ دقیقه‌ای در صورت ارسال بیش از ۵۰ درخواست در ۱۰ ثانیه.
5. **موتور تولید اسنپ‌شات چارت:**
   - رندر چارت‌های کندل‌استیک تیره با `mplfinance` در ترد مجزا (`asyncio.to_thread`) با پس‌زمینه بدون گرافیک `Agg` و جلوگیری از Memory Leak.
   - خطوط ورود (آبی)، حد ضرر (قرمز) و حد سود (سبز).
   - پایپ‌لاین آپلود امن تصویر چارت با Pillow: اعتبارسنجی بایت‌ها، حذف EXIF و بهینه‌سازی تناسبی به فرمت WebP.
6. **دیده‌بان سلامت سیستم (Watchdog) و مانیتورینگ:**
   - گزارش‌دهی خودکار وضعیت دیتابیس، فضای دیسک و سلامت اتصال به کانال تلگرام ادمین با مکانیزم جلوگیری از تکرار لاگ (Throttling).
   - هشدار افت سرمایه هفتگی (Weekly Drawdown Guard) به محض ثبت ترید زیان‌ده (SL).
7. **ربات تلگرام و FSM هوشمند:**
   - منوی شیشه‌ای و دکمه WebApp برای راه‌اندازی مینی‌اپ.
   - فرآیند ۴ مرحله‌ای ثبت هشدار هوشمند قیمتی/درصدی (`AlertFSM`).
   - غربالگر لحظه‌ای قیمت ۶ ارز برتر بازار با `ccxt`.
   - پنل ادمین تلگرامی برای مسدودسازی سریع کاربران و روشن/خاموش کردن حالت تعمیر (Maintenance).

## ۳. نحوه راه‌اندازی و اجرا

### الف) اجرای سریع با پایتون و نود (Local Development)

#### ۱. راه‌اندازی بک‌اند:
```powershell
# ورود به پوشه بک‌اند
cd backend

# فعال‌سازی محیط مجازی و نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای مایگریشن‌های دیتابیس (اختیاری)
alembic upgrade head

# اجرای سرور FastAPI و ربات تلگرام
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
مستندات تعاملی Swagger در آدرس `http://localhost:8000/docs` در دسترس است.

#### ۲. اجرای فرانت‌اند (مینی‌اپلیکیشن):
```powershell
# ورود به پوشه فرانت‌اند
cd frontend

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه Vite
npm run dev
```
مینی‌اپلیکیشن در آدرس `http://localhost:5173` باز خواهد شد.

### ب) اجرای تست‌های خودکار بک‌اند:
```powershell
cd backend
pytest -v
```
تمام ۱۱ تست مربوط به ماشین‌حساب، امنیت، Rate Limiter و اندپوینت‌های REST پاس خواهند شد.

### ج) استقرار با Docker Compose (Production):
```bash
docker-compose up -d --build
```
این دستور کانتینرهای PostgreSQL 16، FastAPI Backend و Nginx Frontend را به صورت خودکار بیلد و بالا می‌آورد.
